## 数据流程

### 1. 添加API数据源

```
用户操作
   │
   ├─> 点击"添加数据源"
   │
   ├─> 填写配置表单
   │   ├─ 数据源名称
   │   ├─ 接口类型（单接口/列表+详情）
   │   ├─ API地址
   │   └─ 字段路径
   │
   ├─> 点击"保存"
   │
   └─> POST /api/sources
       │
       ├─> api_source.add_api_source()
       │
       └─> 保存到 api_sources.json
```

### 2. 同步数据流程

```
用户点击"同步"
   │
   └─> POST /api/sources/{id}/sync
       │
       ├─> api_source.sync_api_source()
       │   │
       │   ├─> 1. 加载配置
       │   │
       │   ├─> 2. fetch_api_data()
       │   │   │
       │   │   ├─ 单接口模式:
       │   │   │  └─> HTTP GET → 提取内容
       │   │   │
       │   │   └─ 列表+详情模式:
       │   │      ├─> HTTP GET 列表接口
       │   │      ├─> 提取ID列表
       │   │      └─> 逐个调用详情接口
       │   │
       │   ├─> 3. 遍历内容
       │   │   │
       │   │   └─> rag.ingest_document()
       │   │       ├─> 文本分块
       │   │       └─> 保存元数据
       │   │
       │   └─> 4. 返回文档ID列表
       │
       └─> 5. 后台向量化
           │
           └─> asyncio.create_task(_bg_embed())
               │
               ├─> rag.re_embed_document()
               │   ├─> 调用Embedding API
               │   └─> 写入Chroma DB
               │
               └─> 前端轮询显示进度
```

### 3. 字段路径解析

```
JSON数据:
{
  "results": {
    "items": [
      {"id": "1", "content": "内容1"},
      {"id": "2", "content": "内容2"}
    ]
  }
}

路径解析:
┌─────────────────────┬──────────────────────┐
│ 路径                │ 结果                  │
├─────────────────────┼──────────────────────┤
│ results.items[].id  │ ["1", "2"]           │
│ results.items[0].id │ "1"                  │
│ results.items       │ [{...}, {...}]       │
└─────────────────────┴──────────────────────┘

实现逻辑:
_get_nested_value(data, path)
   │
   ├─> 分割路径: "results.items[].id"
   │   └─> ["results", "items[]", "id"]
   │
   ├─> 逐层访问:
   │   ├─> data["results"]
   │   ├─> ["items[]"] → 识别数组语法
   │   └─> 对每个元素提取 ["id"]
   │
   └─> 返回结果列表
```
